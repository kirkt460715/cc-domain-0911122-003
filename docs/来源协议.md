# 维护说明文档
python3 -m lab.documents /tmp/manual.docx 生成合成文档。范围包括 document、numbering、footnotes 和它们的 relationships；正文结构为段落、run、插入/删除、moveFrom/moveTo、hyperlink、numPr 与 table。编号支持 decimal、bullet 两种，一级和多级引用、start、startOverride；表格 gridSpan、vMerge 延续格不能重复正文。脚注在正文引用处展开一次并保留标识，多次引用保留引用关系。接受视图包含 ins/moveTo，修订前视图包含 del/moveFrom。段落与单元格路径用于来源位置，样式字体不影响正文。外部链接不抓取，嵌入对象、绘图和 altChunk 作为不支持结构报告。
合成文档同时展示两种修订、一级与二级列表、从五重新编号、横向合并表格、被引用及未引用脚注、页眉和可见超链接。它只生成源文件，不实现正文采集或 Corpus Gate 适配。

## DOCX 采集入口（corpus_gate.docx）

采集只处理上文列明的 OOXML 范围：document、numbering、footnotes 及 document 关系；其余包内成员登记为范围外证据，不解析也不跟随。超链接只保留可见文字，关系目标不解析、不访问；页眉、页脚、批注和未被正文引用的脚注不进入正文。嵌入对象、绘图（w:drawing/w:pict/w:object）、altChunk、未知关系等不支持结构必须带位置上报，提取结果因此不可确认；提取结果为空同样按失败处理，不交付看似完整的空文本。

操作员在 `docx-preview` 中显式选择视图：`accepted`（接受修订后的正文，保留 w:ins/w:moveTo，剔除 w:del/w:moveFrom）或 `original`（修订前正文，保留 w:del/w:moveFrom，剔除 w:ins/w:moveTo）。提取规则以 `corpus-gate-ooxml-wordprocessingml` 名称和整数 rule_version 标识，规则与视图、原始包 sha256 一起写入不可篡改的预览记录。

正文按文档顺序输出段落、嵌套编号项、表格单元格和在首次引用处展开的脚注；编号实现 decimal、bullet，支持多级、start 与 startOverride 重启/覆盖；gridSpan 与 vMerge 延续格只输出一次，同一段文字不会因合并而重复；脚注正文只在首次引用处展开一次，后续引用仅保留引用关系（footnote_reference 块）。每个块都带 OOXML 来源位置（/body/p[n]、/body/tbl[n]/tr[n]/tc[n]/p[n]、word/footnotes.xml#footnote-id），确认入库时位置映射与映射摘要进入文档 metadata，原始文件名、包摘要、视图和规则版本可追溯。

预览与确认分两步：`docx-preview` 先做来源授权并返回正文、逐块位置映射、脚注引用情况和不支持结构报告；`docx-confirm` 复核摘要后通过既有 batch/profile 管道进入文本配置、近重复分组与人工审查。同一原始文件可分别按两种视图或不同规则版本提取，用 `docx-compare` 比较；已经确认或已审查的文档版本不可被重新提取覆盖，必须使用更高的 version。授权撤回后预览只保留 denied 失败记录，确认被拒绝且不产生文档。
